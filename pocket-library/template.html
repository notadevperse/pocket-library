How to play these on Android

These free apps run your PC games on an Android phone or handheld itself, with no streaming from a PC. They use compatibility layers that let the Windows version of a game run there: DroidDeck runs Valve's own Steam client and Proton inside a small Linux system, much like a Steam Deck; GameNative uses Proton or Wine; GameHub Lite uses Wine. They work best on a recent Snapdragon chip (Snapdragon 8 Gen 2 or newer, as in many flagship phones, the AYN Odin 2, and the AYN Thor).

The three apps

Tips

  • Render 3D games at 720p and turn on FSR upscaling. It looks sharp on a small screen and runs much faster.
  • If a game won't start in one app, try it in another. Each one handles games differently.
  • Phones have no fan. Cap heavy games at 30 or 40 FPS for long sessions. Handhelds with a fan can push harder.
  • For Touch games, turn on direct touch so a tap clicks where your finger is: Direct touch in DroidDeck, touchscreen mode in GameNative.
  • Games whose anti-cheat blocks Linux won't run in any of these apps. Use a PC or cloud gaming for those.
What this page shows

Weight: how demanding the game is

  • Light: 2D, indie, older, or light 3D games. Should run well.
  • Medium: older or mid-weight 3D. Use 720p with FSR.
  • Heavy: modern or demanding 3D. Playable with compromises at 720p with FSR.
  • Android app: there's a native Android version, which beats running the PC one.
  • Not on Android: blocked by anti-cheat, VR only, servers shut down, or far too demanding.
  • Unknown: no data yet.

Reports: what players found

  • ProtonDB: whether the game runs on Linux PCs, from ProtonDB reports. The Android apps build on the same tools, so a game that fails there usually fails here too.
  • GameNative: what GameNative players on Snapdragon devices reported, for games with 20 or more ratings.
  • Anti-cheat: whether the game's anti-cheat allows Linux, from AreWeAntiCheatYet.
  • DroidDeck and GameHub Lite don't publish compatibility data yet, so there are no reports for them.

The rest

  • Touch / Touch OK / Controller: how well it plays without a gamepad. A note, not a rule.
  • Heads-up: an extra hurdle, like a publisher launcher (EA, Ubisoft, Rockstar).
  • Changed: what changed for the game in the latest monthly data, such as a new GameNative verdict. "Changed lately" under Filters shows only those games.
  • Based on: the data behind the entry: Steam's minimum requirements, ProtonDB, GameNative, the anti-cheat list, or a check by hand. "Estimate only" means there was no data.
